# ポートフォリオサイト

## 目的
- このリポジトリはReactを用いた静的ポートフォリオサイトです
- Reactを途切れ途切れで学習した筆者がReactを線で結ぶために作りました
- 出来る限り現実の開発のようなプロセスで開発を進める。GitHubを活用する

## 決まりごと
- 環境構築のフレームワークはviteを使用
- commitメッセージはConventional Commitsを参考にする
- issueは随時建てるがメモ書き程度に留め、Reactの調査に集中
- AIも活用はするが出来る限りは最新のドキュメントを確認すること
